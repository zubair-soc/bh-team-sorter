# Instructions for coding assistants

1. Read `PROJECT_HANDOFF.md`, `DECISIONS.md`, and `README.md` (if present) before modifying this project.
2. Verify the active branch, latest commit, application architecture, deployment, and backend. Do not assume `main` contains unfinished work from another branch.
3. Protect existing application behavior; do not overwrite unfinished work based on stale chat summaries.
4. Do not deploy or change production data without explicit user approval.
5. After substantive development, update `PROJECT_HANDOFF.md` with the branch/commit, changes, actual tests, preview/live status, known issues and next actions. Record lasting decisions in `DECISIONS.md`.
6. Never include secrets, tokens, customer data, player PII or sensitive environment variables in repository documentation.
